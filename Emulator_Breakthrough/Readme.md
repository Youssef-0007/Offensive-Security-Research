# Yan85 Reverse Engineering & Exploitation Toolchain
This repository contains a comprehensive suite of tools and a detailed write-up for analyzing, deconstructing, and exploiting the Yan85 Virtual Machine, specifically targeting the randomized "yansanity-hard" levels from the pwn.college architecture challenges.

🚀 # Project Overview
The Yan85 VM is a custom emulator with a randomized Instruction Set Architecture (ISA). To defeat it, this project moves from initial black-box observation to full ISA reconstruction and automated payload generation.
